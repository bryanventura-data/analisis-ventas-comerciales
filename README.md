# 📊 Análisis de Ventas Comerciales

Proyecto de análisis de ventas end-to-end: modelado de datos con **MySQL**, 
consultas SQL para exploración y validación, y un **dashboard interactivo en Power BI** 
para el seguimiento de KPIs comerciales.
